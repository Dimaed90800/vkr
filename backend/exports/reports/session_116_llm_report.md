1. Провести аудит контроля доступа для всех объектных endpoints, чтобы убедиться, что пользователи имеют доступ только к тем объектам, к которым они должны иметь доступ.

## Итоговая оценка
Общее состояние безопасности API "crapi" требует внимания. Выявленные проблемы с контролем доступа могут привести к серьёзным последствиям, включая утечку данных и несанкционированный доступ.
