# Итоговый отчёт по результатам автоматизированного тестирования безопасности REST API

## Краткое резюме
В ходе автоматизированного тестирования безопасности REST API для цели "crapi" было выявлено 7 находок, из которых 5 являются кандидатами на нарушение объектного разграничения доступа (BOLA). Все находки подтверждены, что указывает на наличие потенциальных уязвимостей, требующих внимания.

## Основные находки

1. **Тип:** Возможное нарушение уровня авторизации объекта (BOPLA)  
   **Endpoint:** http://host.docker.internal:8888/community/api/v2/community/posts/recent  
   **Уровень критичности:** Средний  
   **Статус верификации:** Подтверждено  
   **Краткое описание:** Ответ на запрос к данному endpoint раскрывает потенциально чувствительные поля: posts.author.email.  
   **Интерпретация результата:** Утечка данных может привести к компрометации личной информации пользователей.

2. **Тип:** Возможное нарушение уровня авторизации объекта (BOLA)

   **Уровень критичности:** Высокий

   **Интерпретация результата:** Это указывает на возможность несанкционированного доступа к объектам, что может привести к утечке конфиденциальной информации.

## Рекомендации по устранению
1. Провести аудит и улучшить механизмы контроля доступа для всех объектных endpoints, чтобы предотвратить несанкционированный доступ.
2. Ограничить доступ к чувствительным полям в ответах API, особенно к данным, которые могут быть использованы для компрометации личной информации.
3. Провести ручную проверку маршрутов, указанных в диагностических сигналах, для выявления возможных уязвимостей в аутентификации и авторизации.

## Итоговая оценка
Обнаруженные уязвимости представляют собой значительные риски для безопасности данных и конфиденциальности пользователей. Рекомендуется немедленно принять меры по устранению выявленных проблем и провести дополнительное тестирование для подтверждения исправлений.
