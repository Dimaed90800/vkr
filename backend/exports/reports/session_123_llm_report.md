# Итоговый отчёт по результатам тестирования безопасности REST API

## Краткое резюме
В ходе автоматизированного тестирования безопасности REST API для цели "crapi" были выявлены 7 находок, из которых 6 подтверждены, а 1 является кандидатом на дальнейшую верификацию. Основные проблемы связаны с возможными нарушениями объектного разграничения доступа (BOLA) и избыточным раскрытием данных.

## Основные находки

1. **Тип:** Возможное нарушение уровня авторизации объекта (BOPLA)  
   **Endpoint:** http://host.docker.internal:8888/community/api/v2/community/posts/recent  
   **Уровень критичности:** Средний  
   **Статус верификации:** Подтверждено  
   **Краткое описание:** Ответ на запрос к данному endpoint раскрывает потенциально чувствительные поля: posts.author.email.  
   **Интерпретация результата:** Наличие чувствительных данных в ответе может привести к утечке личной информации пользователей.

2. **Тип:** Возможное нарушение уровня авторизации объекта (BOLA)

## Рекомендации по устранению
1. **Для BOPLA находок:** Необходимо ограничить доступ к чувствительным полям в ответах API. Рекомендуется использовать механизмы фильтрации данных в зависимости от ролей пользователей.
2. **Для BOLA находок:** Рекомендуется провести аудит контроля доступа к объектам, чтобы убедиться, что пользователи имеют доступ только к тем объектам, которые им принадлежат. Необходимо внедрить строгие проверки прав доступа на уровне объектов.
3. **Для диагностического сигнала:** Рекомендуется провести ручную проверку маршрута и методов, чтобы убедиться в правильной настройке аутентификации и авторизации для данного endpoint.

## Итоговая оценка
Общее состояние безопасности API "crapi" требует внимания, так как были выявлены серьезные проблемы с объектным разграничением доступа и избыточным раскрытием данных. Рекомендуется провести ручную верификацию кандидатов на уязвимости и реализовать предложенные меры по устранению выявленных проблем.
