Ключевое уточнение: агенты не являются просто кнопками запуска инструментов. Инструменты дают signals/observations, агенты интерпретируют их и планируют verification/exploitation, backend выполняет bounded commands/jobs, а Judge получает только EvidencePack, а не raw scanner output.

Для долгих инструментов: RESTler, Schemathesis, CATS, ZAP active scan, nuclei, ffuf/Kiterunner и Playwright crawl запускаются как ToolRun jobs. Сначала возвращается tool_run_id, затем backend собирает результат, нормализует observations, обновляет corpus/graph и только после этого строит EvidencePack.
